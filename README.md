# Nickname OSINT Tool

Простой CLI-инструмент для поиска публичных профилей по никнейму.

## Возможности
- Проверка никнейма на популярных сайтах (GitHub, Reddit, Instagram и т.д.).
- Параллельные запросы.
- Вывод в виде таблицы или JSON.
- Работает только с публично доступными страницами.

## Запуск
```bash
python3 osint_nickname.py username
```

Проверить только конкретные сайты:
```bash
python3 osint_nickname.py username --site GitHub --site Reddit
```

JSON-формат:
```bash
python3 osint_nickname.py username --json
```

## Важно
Используйте инструмент ответственно и только в рамках закона. Результат `found=yes` означает, что страница по URL доступна, но не гарантирует, что профиль принадлежит конкретному человеку.
